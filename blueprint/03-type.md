# Type

Three free fonts from one straight, engineered family of looks. All are on Google Fonts and in Canva, so they work in every tool we use.

| Role | Font | Weights | Use |
| --- | --- | --- | --- |
| Display | **Archivo Narrow** | 600, 700 | Names, headlines. Uppercase for names, sentence case for headlines. |
| Text | **IBM Plex Sans** | 400, 500 | Body copy, website text, platform points. |
| Label | **IBM Plex Mono** | 400, 500 | Small labels, dates, positions, page numbers. Always uppercase with wide spacing. |

Download: fonts.google.com (search each name). Put offline copies in `assets/fonts/` if needed.

## Scale

| Style | Font | Size (web / social) | Line height | Notes |
| --- | --- | --- | --- | --- |
| `display` | Archivo Narrow 700 | 96px | 0.92 | Posters, cover slides. Tight tracking (-1%). |
| `headline` | Archivo Narrow 700 | 56px | 0.95 | |
| `title` | Archivo Narrow 600 | 32px | 1.05 | |
| `body-lg` | IBM Plex Sans 400 | 20px | 1.45 | Lead paragraph. |
| `body` | IBM Plex Sans 400 | 16px | 1.5 | |
| `label` | IBM Plex Mono 500 | 12px | 1.3 | UPPERCASE, letter-spacing +8%. |
| `caption` | IBM Plex Mono 400 | 11px | 1.4 | Fine print. |

For print, scale everything together: on an 11×17 poster, `display` is roughly 150–220pt.

## How the names are set
- Ticket label: `POTIÉ / BIGGAR` — Archivo Narrow 700, uppercase, a thin slash with a space either side.
- With roles: a `label` line (`PRESIDENT`, `VICE PRESIDENT`) above each name.
- Until there's a real logo, this typeset name IS the logo. Don't draw one.

## Don't
- No script, handwritten, bubble, or novelty fonts. No outline or 3D text.
- No more than three sizes on one piece.
- No centered body paragraphs. Left-align text; center only a single short line if the layout needs it.
